# Security policy and demo limitations

FieldOps is a **client-side demonstration**. It should not be used to store real customers, payment information, medical information or other sensitive business data. There is no authentication, tenant separation, server persistence, encrypted storage or live integration.

Before production use, implement a server-side security model, auth/authorization, audit trails, retention policies, rate limiting, encryption, backup testing, incident response and security testing.

Please report issues through a private channel rather than publicly posting secrets or customer information. Repository ownership and contact channels should be added when publishing.
